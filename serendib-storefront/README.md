# Serendib Still Breathes — Steam-Style Storefront Concept

An unofficial storefront concept for Serendib Still Breathes. I designed the store page around the game’s cinematic trailer and screenshot gallery, with separate pages for development news, discussions and support. Visitors can try the wishlist, follow and discussion features in their browser. The prototype is independent of Valve and Steam.

[Visit the live project](https://serendib-still-breathes.wittynova34.chatgpt.site/steam.html)

Open `index.html` in this project folder. The GitHub Pages copy is at https://lakmalmas.github.io/serendib-storefront/. To test locally, run `python -m http.server 8000` and visit http://localhost:8000/.
