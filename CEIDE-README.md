# CEIDE — Build worlds. Build your future.

CEIDE is Lakmal MAS's multimedia web design project for aspiring 3D artists, animators and game makers. The redesigned site carries the original brief through three connected areas: learning, portfolios and careers.

- **Learn:** Six short courses for Blender, Unreal Engine and Maya, each with three steps, a practice task per lesson, a quiz and a link to official resources.
- **Showcase:** Featured work, a personal portfolio editor, and export to a standalone HTML page.
- **Careers:** Search and filter the studio directory, bookmark studios and follow their official career links. CEIDE does not list live vacancies.
- **My Studio:** Review completed lessons, edit your portfolio and manage bookmarks. Progress and projects are stored per browser through local storage.

The site is plain HTML, CSS and JavaScript with no build step. For a local preview, open a terminal in this directory and run `python -m http.server 8000`. Open http://localhost:8000 in your browser. On GitHub Pages, the original routes forward to their corresponding sections.

The CEIDE mascot and course illustrations were generated with OpenAI Image Generation and processed for the site. The Serendib Still Breathes image is from the linked showcase project by Lakmal MAS / Studio 141. Software and studio names identify their respective products and organizations.
