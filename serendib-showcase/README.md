# Serendib Still Breathes — Game Showcase Website

The game showcase for Serendib Still Breathes, a third-person survival adventure set in a fictional post-apocalyptic Sri Lanka. An interactive world explorer introduces the bunker, Jungle Gorge and Colombo. The site also gives visitors access to the cinematic trailer, a filterable screenshot gallery, a FAQ and a downloadable press kit.

[Visit the live project](https://serendib-still-breathes.wittynova34.chatgpt.site/)

Open `index.html` in this project folder. The GitHub Pages copy is at https://lakmalmas.github.io/serendib-showcase/. To test locally, run `python -m http.server 8000` and visit http://localhost:8000/.
